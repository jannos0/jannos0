## About me

I build reliable, repeatable cloud infrastructure and delivery workflows for enterprise systems. My focus centers on Infrastructure as Code (IaC), GitOps-based Kubernetes delivery, end-to-end CI/CD optimization, environment parity, and operational support that keeps releases moving safely.

Currently, I specialize in designing, deploying, and maintaining production **Azure & AKS** environments using **Bicep (AVM)** and **Argo CD**, while streamlining local and cloud developer workflows.

---

## What I work on

- **Infrastructure as Code (IaC):** Designing, deploying, and managing scalable Azure environments (AKS, databases, messaging, monitoring) using **Bicep IaC (Azure Verified Modules)** for modular, pipeline-driven deployments.
- **GitOps & Kubernetes:** Managing containerized microservices and enterprise AKS deployments using declarative GitOps practices with **Argo CD** and **Helm**.
- **Release & Platform Engineering:** End-to-end ownership and continuous optimization of Azure DevOps pipelines, reducing build/deployment times and enforcing release controls.
- **Cluster Upgrades & Maintenance:** Planning and running AKS version upgrades via Azure Automation across environments, complete with comprehensive upgrade and rollback plans.
- **Self-Hosted Infrastructure:** Configuring and maintaining self-hosted Azure DevOps VMSS agents (Linux/Windows) via Bicep and **Azure Image Builder** tailored to project requirements.
- **Local Developer Parity:** Maintaining and enhancing a containerized local development environment using **Podman** to mirror cloud infrastructure 1:1, accelerating onboarding and debugging.
- **AI & Workflow Automation:** Leveraging Claude AI with **Model Context Protocol (MCP)** and Agentic Skills to automate intelligent workflows, facilitate Agent-to-Agent (A2A) communication, and optimize token usage.
- **Operations & Documentation:** Maintaining operational health, security, cost optimization, and pipeline monitoring while authoring internal technical wikis to support cross-functional Agile sprints.
