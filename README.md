## About me

I build reliable, repeatable cloud infrastructure and delivery workflows for enterprise systems. My work focuses on Infrastructure as Code, CI/CD automation, GitOps-based Kubernetes delivery, environment parity, and the operational support that keeps releases moving.

I currently work with Azure DevOps, Azure Bicep, Kubernetes/AKS, Argo CD, and Podman while supporting a large-scale cloud modernization initiative.

## What I work on

- **Infrastructure as Code:** Modular Azure Bicep templates for reviewable, source-controlled provisioning across environments
- **CI/CD:** Automated build, deployment, patch-management, branching, tagging, and release workflows in Azure DevOps
- **GitOps:** Declarative Kubernetes application delivery and environment reconciliation with Argo CD
- **Platform engineering:** Containerized local environments with Podman, designed for stronger local-to-cloud parity
- **Operations:** Pipeline monitoring, release troubleshooting, environment maintenance, documentation, and cross-team support
- **Observability:** Monitoring and logging workflows using Prometheus, Grafana, ELK, and Zabbix
